Exportador de votos de FilmAffinity

FilmAffinity bloquea las peticiones desde servidores (Cloudflare), así que el perfil se extrae desde tu propio navegador, que ya tiene acceso autorizado.

1 · Añade el marcador

Arrastra este enlace a la barra de marcadores (si no ves la barra, pulsa Ctrl+Mayús+B):

Exportar votos de cine

2 · Usa el marcador
  1. Abre tu perfil de votaciones en vista lista.
  2. Pulsa el marcador. Aparecerá un cuadro con dos opciones:
    • Aceptar = solo primera página (~50 votos recientes). Se descarga el JSON inmediatamente.
    • Cancelar = todas las páginas (~622 votos). El marcador saltará a la siguiente página y terminará en la última.
  3. En la última página o en la primera (según la opción elegida) se descargará wobocobo-cine-ratings.json.
3 · Publica los datos

Sustituye el contenido de data/ratings.json por el JSON descargado y sube los cambios. cine.html mostrará las valoraciones automáticamente.
